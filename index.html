Open the marker

Marker Hiro, the ARToolKit standard. Print it, or open it on a second screen and point the phone at that.

Works on Android Chrome and iOS Safari, over HTTPS only. Camera access is asked for once and never leaves the device — nothing is uploaded, there is no backend.

No marker Preview mode renders the same scene with mouse or touch orbit, no camera involved. It is the object, not the tracking.

In the room On WebXR-capable devices — most recent Android phones — the object can be placed on a real floor or table instead, with no marker at all. The button appears only when the device can do it.

Content What the marker carries is described in content.json — models, decoration and tracking parameters. Swapping it is an edit to that file, not a code change.
